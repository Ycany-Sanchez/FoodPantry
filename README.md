# Food Suggester App

PantryPlanner is a mobile Android application designed to reduce food waste and simplify meal planning by recommending recipes based on ingredients users already have at home. Instead of searching for recipes first and then buying ingredients, PantryPlanner works in reverse — users simply enter the ingredients available in their pantry, and the application finds recipes they can immediately prepare.

The main goal of PantryPlanner is to make cooking more convenient, reduce unnecessary grocery spending, and help users maximize the ingredients they already own.

This was a Kotlin project for mobile development as well as learning about implementation of API's
